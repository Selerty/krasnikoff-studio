# Krasnikoff Studio — dark glass concept

Контентная версия сайта студии в исходной кинематографичной концепции: тёмный фон, стеклянные поверхности, яркий градиент, анимированное видео и интерактивный интерфейс-мокап.

Стек: React 18, TypeScript, Vite, Tailwind CSS, Motion, Lucide.

## Запуск

```sh
npm install
npm run dev
```

Production-сборка: `npm run build`.

В содержание входят только подтверждённые услуги, ценовые ориентиры и контакт студии. Вместо вымышленных логотипов и отзывов размещены типовые задачи и принципы работы. Видео остаётся фоновым визуальным материалом исходной концепции.
