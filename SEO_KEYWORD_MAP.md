# Карта поисковых формулировок

Обновлено: 9 ноября 2026 года.

## Состояние исследования

Собрана предварительная карта коммерческих формулировок по русскоязычной выдаче и страницам веб-студий. В Яндекс Вордстате выполнен вход и проверен запрос «разработка сайтов», но сервис сообщил о временной недоступности части данных и не вернул подходящие запросы. Поэтому частотность, региональный спрос и относительные приоритеты пока не подтверждены; эти пункты нельзя считать семантическим ядром.

## Предварительная карта

| Намерение | Формулировки для проверки | Где раскрывать сейчас |
|---|---|---|
| Заказать разработку сайта | разработка сайтов для компаний; разработка сайта для бизнеса; создание сайта компании | Главная: первый экран и описание студии |
| Одностраничный сайт | разработка лендинга; создание лендинга; заказать лендинг | Карточка «Лендинг»; отдельная страница только при наличии полезного уникального содержания |
| Многостраничный сайт | разработка корпоративного сайта; создание сайта компании; сайт услуг для компании | Карточка «Сайт компании»; отдельная страница после проверки спроса и подготовки материалов |
| Каталог | разработка сайта-каталога; каталог товаров на сайте | Карточка «Каталог» |
| Продажи онлайн | разработка интернет-магазина; создание интернет-магазина | Карточка «Интернет-магазин» |

Пока сайт одностраничный, эти намерения остаются разделами одной страницы. Не создавать отдельные страницы, состоящие только из переставленных ключевых слов.

## География

В `PRODUCT.md` указано, что сайт студии не ограничивает работу регионом. Поэтому тексты не привязываются к Самарской области или отдельному городу. Локальные модификаторы добавлять только после решения о фактической географии продаж и проверки спроса.

## Источники и следующий пересмотр

- [Яндекс Вордстат](https://wordstat.yandex.ru/) — источник частотности; повторить выгрузку после восстановления данных, проверить Россию и Самарскую область отдельно.
- [Страница разработки сайта компании Visualweb](https://visualweb.ru/sozdanie-sajta/korporativnyj-sajt/) — пример употребления «создание сайта компании» и «корпоративный сайт» в коммерческой выдаче.
- [Страница разработки сайтов АйТи-Стандарт](https://it-std.ru/uslugi/razrabotka-saytov/) — примеры разделения спроса по лендингу, сайту компании и интернет-магазину.
- После подтверждения сайта в Search Console и Яндекс Вебмастере сверить эту карту с реальными запросами, показами и переходами и пересмотреть её.
